Capabilities

Engineered for Performance and Total Privacy

Unlike cloud assistants that stream raw microphone feeds to external datacenters, Ultron executes speech recognition, intent resolution, and system actions strictly on local hardware.

01

Pure Offline Operation

Zero network roundtrips required. Operates with full speech decoding, classification, and device automation even in airplane mode or air-gapped environments without SIM cards or Wi-Fi.

02

Acoustic Phonetic Normalizer

Solves acoustic decoder ambiguity when Vosk STT outputs phonetically adjacent variations (such as "all thrown", "all drone", or "out run") by mapping them back to canonical wake intents.

03

Chained Multi-Step Automation

Parses conjunctions such as "and", "then", or "after that" to break complex instructions into sequential actions, executing multi-step routines with deterministic handoff delays.

04

Ultra-Compact 372 KB Binary

Compiled without heavy third-party SDKs, Google Play Services dependencies, or analytics bloatware. Targets clean Java 7 bytecode with maximum backward compatibility across Android 7 to 14.

05

Always-On-Top Floating HUD

Draggable desktop-style overlay widget accessible over any running Android app. Features four distinct dynamic glow states for Idle, Listening, Processing, and Speaking modes.

06

Direct Framework Integration

Controls system hardware interfaces directly via native Android framework classes including WifiManager, BluetoothAdapter, NotificationListenerService, and StatusBarManager.

Terms of Service & Privacy Policy

1. Complete Local Privacy Guarantee

Ultron Assistant does not transmit audio recordings, text transcriptions, command histories, device identifiers, or usage telemetry to any external server or third-party service. All computation occurs strictly in local device memory.

2. System Permissions Utilization

The application requests strictly necessary Android runtime permissions:

  • RECORD_AUDIO: Required for real-time speech recognition by Vosk STT. Audio frames are processed in volatile memory and never persisted to disk or streamed externally.
  • SYSTEM_ALERT_WINDOW: Required solely to render the floating HUD overlay widget above other applications.
  • WRITE_EXTERNAL_STORAGE: Optional; utilized only if you instruct the assistant to create local text notes.
